# 게이트웨이 검증 노트

`MassFlux-Gateway`는 비표준 TCP 패킷을 받아서 장비 ID와 센서 값을 추출하고,
외부 API로 전달하는 구조를 실험한 프로젝트입니다.

처음에는 Netty 기반 구조와 처리량 개선에 초점을 맞췄지만, 다시 보니
“빠르다”는 말보다 “어떤 입력을 어떻게 처리하는지 테스트로 확인했다”는 근거가
더 중요했습니다.

## 현재 코드에서 확인한 부분

- `FluxDecoderTest`
  - ASCII 구간을 잘라 장비 ID를 읽는지 확인했습니다.
  - 요청한 구간이 버퍼 범위를 넘을 때 빈 문자열을 반환하는지 확인했습니다.
  - little-endian float 값을 의도대로 읽는지 확인했습니다.

- `GatewayHandlerTest`
  - 정상 패킷을 `SensorPacket`으로 변환해 API 서비스로 넘기는지 확인했습니다.
  - 길이가 짧거나 STX가 잘못된 패킷은 처리하지 않는지 확인했습니다.

## 로컬 확인 명령

```bash
mvn clean verify
```

## 다음에 보강하고 싶은 부분

| 항목 | 이유 |
| --- | --- |
| TCP 패킷 처리량 측정 | PPS 수치를 같은 조건에서 다시 비교할 수 있게 남기기 위해 |
| API 실패/재시도 테스트 | 외부 API 장애 상황에서 어떻게 동작하는지 보여주기 위해 |
| ByteBuf release 검증 | Netty 기반 코드에서 메모리 누수 위험을 줄이기 위해 |
| Docker 이미지 크기 기록 | 컨테이너 경량화 효과를 수치로 확인하기 위해 |

성능 수치는 측정 스크립트나 실행 결과를 같이 남기는 방향으로 정리할 예정입니다.
